# Карточки игроков

Две самостоятельные карточки: `neko.html` и `human.html`. Изучены только владения категорией и конкретным оружием 1-го уровня. Боевые способности ещё не изучены.

На карточках: стартовые ХП, туника без бонусов, характеристики, оружие, владения, статус боевых способностей и краткая памятка. Это статические карточки: значения в ходе игры сами не меняются.

Обновление: измените данные в `build.mjs`, затем выполните `node build.mjs`. Просмотр не требует установки зависимостей.

Для GitHub Pages: ветка `master`, папка `/`. Файлы `index.html`, `neko.html`, `human.html`, `styles.css`, `.nojekyll` должны оставаться вместе.
