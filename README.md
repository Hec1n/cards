# Карточки игроков

Две самостоятельные карточки: `neko.html` и `human.html`. Изучены только владения категорией и конкретным оружием 1-го уровня. Боевые способности ещё не изучены.

На карточках: стартовые ХП, туника без бонусов, характеристики, оружие, владения, статус боевых способностей и краткая памятка. ХП меняются кнопками −1/+1 от 0 до текущего максимума. Монеты изменяются на указанную сумму, не ниже нуля. Вещи добавляются по названию и количеству; одинаковые названия объединяются. Кнопка «Убрать» удаляет запись целиком. ХП, монеты и вещи сохраняются в localStorage отдельно для каждого персонажа и браузера. Между устройствами и игроками синхронизации нет. Начальные монеты не назначены: счётчик начинается с 0 для ручного учёта.

Обновление: измените данные в `build.mjs`, затем выполните `node build.mjs`. Просмотр не требует установки зависимостей.

Для GitHub Pages: ветка `master`, папка `/`. Файлы `index.html`, `neko.html`, `human.html`, `styles.css`, `card-state.js`, `card.js`, `.nojekyll` должны оставаться вместе.

Проверка логики: `node test-state.mjs`. При недоступности браузерного хранилища карточка сообщает об этом; изменения тогда действуют только до обновления страницы.

Броня: название и бонус к максимуму ХП. Оружие: название, урон, дальность и бонусы к десяти характеристикам. Смена предмета заменяет прежние бонусы, пересчитывает инициативу, движение и ХП от выносливости. При изменении максимума текущие ХП меняются на ту же разницу, сохраняя количество потерянных ХП; при 0 ХП экипировка не поднимает персонажа. Список инвентаря не экипирует предметы автоматически. Все поля хранятся в этом браузере.
